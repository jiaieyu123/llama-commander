# 模块 12：`internal/webui/` — 内嵌前端

## 功能概述

提供基于原生 HTML/CSS/JavaScript + ECharts 5.5 的 Web 界面。使用 `go:embed` 打包为单文件（约 10MB）。

## 核心职责

1. 提供 Web 界面（模型选择、参数配置、实时监控等）
2. 支持多种主题
3. 实时图表渲染

## 技术栈

- **前端**：原生 HTML/CSS/JavaScript
- **图表**：ECharts 5.5（CDN，`go:embed` 打包）
- **主题**：暗色 / 奶白 / SaaS 浅紫 / 紫色

## 界面模块

| 界面 | 功能 |
|------|------|
| 主界面 | 模型选择、参数配置、实时命令预览、运行实例与日志控制台 |
| 性能监控 | KPI 指标卡、吞吐趋势图、每实例实时监控 |
| 运行实例 | 状态徽章、端口、运行时长、一键停止/重启 |
| 日志控制台 | 分级过滤、实例筛选、搜索、自动滚动、导出 |
| 模型库 | 扫描导入、智能捆绑 |
| MCP 工具 | 模板库一键添加、健康检测、绑定模型 |
| 批量测试 | 穷举寻优 / 智能寻优 |
| 使用洞察 | Token 统计、模型热度、吞吐仪表盘 |
| 实时监控 | 每实例趋势图、请求历史、CSV 导出 |
| API 调试 | Chat / Completions / Embeddings 一键调试 |
| 全局设置 | 接口地址、API Key 加密存储、界面主题 |

## 设计亮点

- **单文件打包**：`go:embed` 将前端打包为单文件
- **零构建**：无需前端构建工具链
- **主题系统**：支持多种主题切换
- **实时渲染**：ECharts 实时图表

## 相关调用方

- `cmd/server/main.go`：`go:embed` 加载前端
- HTTP 服务：静态文件服务
